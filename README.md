# 📌 Overview

**CricketConnect Pro** is a modern full-stack cricket management platform designed to streamline:

* team organization
* tournament scheduling
* player networking
* real-time ground booking
* match coordination

The platform provides a scalable ecosystem for cricket communities, organizers, and players to manage their activities efficiently through a responsive web application.

# 🚀 Getting Started

# 1️⃣ Clone Repository

```bash
git clone https://github.com/abhinavsai2006/CricketConnect-Pro.git

cd CricketConnect-Pro
```

---

# 2️⃣ Install Dependencies

```bash
npm install
```

---

# 3️⃣ Start Development Server

```bash
npm run dev
```

---

# 🌐 Deployment

# Deploy to Vercel

```bash
npm run deploy:vercel
```

---

# Deploy to Cloudflare Workers

```bash
npm run deploy
```
